## 🚀 Setup

1. Extract the ZIP.
2. Open your GitHub profile repository.
3. Drag **`README.md`**, **`.github`**, and **`assets`** into the repository root.
4. Commit the changes to `main`.
5. Open **Actions** and run **Generate GitHub Contribution Snake** once.
6. Refresh your profile.

No external image URLs are required for the banner, tool animation or workflow animation.
